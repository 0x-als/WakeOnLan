# Pulse — удалённое управление ПК

Мини-сервер на **FastAPI** для Windows: включает компьютеры по сети (Wake-on-LAN, Magic Packet) и выключает их стандартной командой `shutdown`. Управлять можно с iPhone (веб-приложение + «Команды») и Android (собираемый APK). Дизайн и структура проекта повторяют приложение Lumen.

## Как это работает

```
   iPhone (Safari / «Команды»)         Android (APK)
              │                              │
              └──────────────┬───────────────┘
                             │  Wi-Fi (одна сеть)
                ┌────────────▼────────────┐
                │   ПК-центр с Pulse      │  шлёт Magic Packet,
                │   (всегда включён)      │  хранит список ПК
                └──────┬───────────┬──────┘
          Magic Packet │           │ команда «выключить» (HTTP + ключ)
                ┌──────▼───┐  ┌────▼──────────┐
                │ ПК-цель  │  │ ПК-цель с Pulse│
                │ (выкл.)  │  │ (включён)      │
                └──────────┘  └───────────────┘
```

* **Pulse ставится на каждый ПК**, который нужно уметь выключать (он выключает сам себя).
* **Любой ПК с Pulse может быть «центром»**: телефон подключается к нему, он отправляет Magic Packet и пересылает команду выключения на другие ПК.
* **Выключенный ПК не может включить сам себя.** Чтобы включать ПК по сети, в этой же сети нужен другой работающий ПК/мини-ПК/Raspberry Pi с Pulse. Исключение: **Android-приложение отправляет Magic Packet прямо с телефона** (данные ПК сохраняются в приложении после первого подключения), поэтому для Android центр не обязателен.
* Телефон и ПК должны быть в **одной сети Wi-Fi**.

## Что нужно

* Windows 10/11, **Python 3.10+** (с галочкой «Add python.exe to PATH»).
* Для сборки Android-приложения — Android Studio (см. ниже).

## Установка на ПК (Windows)

1. Скопируйте папку проекта, например, в `C:\Pulse`.
2. Дважды щёлкните **`install.bat`**. Скрипт:
   * создаст виртуальное окружение и установит зависимости;
   * включит автозапуск вместе с Windows;
   * запросит права администратора (UAC) и откроет порты в брандмауэре (TCP 8765, UDP 48765);
   * запустит Pulse в фоне и покажет **ключ доступа** и ссылки для телефона.
3. В трее появится значок Pulse. Меню значка: «Открыть панель», «Скопировать ссылку для телефона», «Запускать вместе с Windows», «Выход».

Повторите установку на каждом ПК, которым хотите управлять. На всех ПК удобно использовать **один и тот же ключ**: откройте `%APPDATA%\Pulse\config.json`, впишите одинаковое значение `token` на всех ПК и перезапустите Pulse (Выход в трее → `run.bat`).

Ручной запуск без установки: `pip install -r requirements.txt`, затем `python main.py`.

Полезные команды: `python main.py --token` (показать ключ и ссылки), `--port 9000` (сменить порт, сохраняется), `--no-tray`, `--uninstall` (убрать автозапуск и правила брандмауэра; то же делает `uninstall.bat`).

> Автозапуск срабатывает **при входе пользователя** в Windows. Если ПК должен быть доступен сразу после включения по сети, включите автоматический вход (`Win+R` → `netplwiz`).

## Первое подключение телефона

1. На ПК откройте `http://localhost:8765` (или «Открыть панель» в трее). Вы увидите интерфейс Pulse.
2. Нажмите значок настроек в правом верхнем углу: там **ссылка для телефона** вида `http://192.168.1.10:8765/?token=ключ`. Скопируйте её и отправьте на телефон (мессенджер, AirDrop и т.п.).

### Главная страница

* Если устройства уже добавлены — показывается список; большая кнопка питания управляет выбранным ПК.
* Если список пуст — предлагается **«Найти компьютеры»**. Pulse ищет ПК с Pulse (мгновенно, по UDP-рассылке) и остальные устройства сети (по таблице ARP, с подбором имён). Нажмите «Добавить» напротив нужных. «Добавить вручную» — свои параметры: MAC, IP, broadcast-адрес, порт Magic Packet.

## Включение ПК по сети (настройка ПК-цели)

1. **BIOS/UEFI**: включите «Wake on LAN» / «Power On By PCI-E» / «Resume by PCI-E device».
2. **Диспетчер устройств → Сетевые адаптеры → ваш адаптер → Свойства**:
   * вкладка «Управление электропитанием»: «Разрешить этому устройству выводить компьютер из ждущего режима» и «Разрешить только магическому пакету…»;
   * вкладка «Дополнительно»: «Wake on Magic Packet» = Enabled.
3. **Электропитание Windows**: отключите «Быстрый запуск» (Панель управления → Электропитание → Действия кнопок питания).
4. Лучше подключать ПК-цель **кабелем Ethernet**: по Wi-Fi большинство компьютеров из выключенного состояния не просыпаются.
5. MAC-адрес берётся автоматически при поиске; вручную: `ipconfig /all` → «Физический адрес».

## iPhone: веб-приложение + «Команды»

**Веб-приложение**

1. Откройте ссылку для телефона в Safari.
2. «Поделиться» → **«На экран “Домой”»**. Ключ доступа сохранится в ярлыке (ссылка содержит его).
3. Через ярлык можно выбирать ПК и **выключать** его (с подтверждением и отменой в течение 10 секунд).

**Включение через «Команды»**

1. Откройте в Pulse устройство (значок «⋯» в списке) — внизу блок **«Для приложения “Команды” на iPhone»** с готовыми ссылками. Скопируйте ссылку «Включить».
2. В «Командах»: «+» → «Добавить действие» → **«Получить содержимое URL»** → вставьте ссылку (метод GET по умолчанию).
3. (Необязательно) добавьте «Показать результат».
4. Назовите команду «Включить ПК», добавьте на экран «Домой» или в виджет; работает и с Siri: «Привет, Siri, включить ПК».
5. При первом запуске iOS спросит доступ к локальной сети — разрешите.

Команда обращается к центру (ПК с Pulse), и тот отправляет Magic Packet. Если центра нет — на роутере/NAS с Wake-on-LAN можно использовать действие «Выполнить сценарий по SSH».

## Android: сборка APK

Приложение — нативная оболочка (Java, WebView) с тем же интерфейсом из папки `ui/`, плюс встроенная отправка Magic Packet и поиск сервера по сети.

**Через Android Studio (рекомендуется)**

1. Установите [Android Studio](https://developer.android.com/studio) (в комплекте JDK 17).
2. `File → Open` → выберите папку **`android`** проекта (папка `ui` должна лежать рядом, на уровень выше).
3. Дождитесь синхронизации Gradle (предложит скачать Android SDK 34 — согласитесь).
4. `Build → Build Bundle(s) / APK(s) → Build APK(s)`.
5. Готовый файл: `android/app/build/outputs/apk/debug/app-debug.apk`. Перенесите на телефон и установите (разрешите установку из неизвестных источников).

**Из командной строки** (нужны JDK 17, Android SDK 34 и переменная `ANDROID_HOME`): в папке `android` один раз выполните `gradle wrapper --gradle-version 8.7`, затем `gradlew assembleDebug` (Windows: `gradlew.bat assembleDebug`).

Для публикации в магазине соберите подписанный release (`Build → Generate Signed Bundle / APK`).

**Использование:** при первом запуске нажмите «Найти сервер в сети» (или введите `http://IP:8765`), введите ключ доступа. Дальше — как в веб-версии. Кнопка «Включить» отправляет Magic Packet напрямую с телефона и дополнительно через сервер.

## Настройки и файлы

* Конфиг: `%APPDATA%\Pulse\config.json` (ключ, порт, имя сервера, список устройств). Лог: `%APPDATA%\Pulse\pulse.log`.
* Порты: HTTP `8765` (меняется `--port`), UDP-поиск `48765`.
* Переменные окружения: `PULSE_HOME` (папка конфига), `PULSE_DRY_RUN=1` (команда выключения только пишется в лог — для проверок).

## HTTP API

Все методы, кроме `/api/health`, требуют ключ: заголовок `X-Pulse-Token: <ключ>` (или `Authorization: Bearer`, или `?token=`). С самого ПК (localhost) ключ не нужен. Интерактивная документация: `http://localhost:8765/docs`.

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/api/health` | проверка (без ключа) |
| GET | `/api/info` | сведения о сервере, адреса, ключ |
| PUT | `/api/system/autostart` | `{"enabled": true}` — автозапуск |
| GET/POST | `/api/devices` | список (со статусами) / добавить |
| PUT/DELETE | `/api/devices/{id}` | изменить / удалить |
| POST | `/api/devices/{id}/wake` | Magic Packet |
| POST | `/api/devices/{id}/shutdown` | `{"delay": 10, "force": false}` |
| POST | `/api/devices/{id}/cancel` | отменить выключение |
| POST | `/api/discovery/scan` | поиск ПК в сети |
| POST | `/api/wake` | произвольный Magic Packet `{"mac","broadcast","port"}` |
| POST | `/api/shutdown`, `/api/shutdown/cancel` | выключить/отменить на этом ПК |
| GET/POST | `/api/shortcuts/wake/{id}`, `/api/shortcuts/shutdown/{id}` | для «Команд» |

## Безопасность

* Доступ защищён ключом (8 символов, генерируется при первом запуске). Не публикуйте ссылку с ключом.
* Сервер рассчитан на **домашнюю сеть**. Не пробрасывайте порт 8765 в интернет; для доступа извне используйте VPN (WireGuard, Tailscale).
* Трафик внутри сети идёт по HTTP без шифрования.

## Если что-то не работает

| Симптом | Что проверить |
|---|---|
| Телефон не видит сервер | одна ли сеть Wi-Fi; правила брандмауэра (`install.bat` или `python main.py --firewall` от администратора); в сети «Общедоступная» откройте порт вручную; на роутере отключите «изоляцию клиентов» (AP isolation) |
| «Найти компьютеры» ничего не находит | включены ли ПК; на ПК должен работать Pulse, чтобы определились имена и статус; нажмите «Без названия» — покажутся все устройства сети |
| ПК не включается | настройки WoL (раздел выше); правильный MAC; broadcast-адрес вашей сети (обычно `192.168.1.255`); попробуйте порт 7 вместо 9; ПК по Wi-Fi почти никогда не просыпается |
| Статус «Выключен», а ПК работает | на ПК нет Pulse, а брандмауэр блокирует ping; установите Pulse и отметьте «Есть сервер Pulse» |
| «Компьютер отклонил ключ доступа» | на ПК-цели другой ключ: сделайте одинаковый `token` в `config.json` |
| Не открывается автозапуск | смотрите `%APPDATA%\Pulse\pulse.log`; переключатель — в настройках Pulse или в меню значка |

## Структура проекта

```
pulse/
├── main.py                 запуск (Application), режимы --install / --uninstall / --token
├── config.py               все константы (Config)
├── requirements.txt
├── install.bat · run.bat · uninstall.bat
├── service/                логика без привязки к вебу
│   ├── settings.py         Settings: ключ, порт, список устройств (config.json)
│   ├── devices.py          Device, DeviceRegistry
│   ├── wake.py             MagicPacket, WakeService
│   ├── power.py            PowerService: shutdown /s, /a
│   ├── agent.py            AgentClient: запросы к Pulse на других ПК
│   ├── actions.py          DeviceActions: включить / выключить / отменить
│   ├── monitor.py          DeviceMonitor: статусы (Pulse, ping, порты)
│   ├── discovery.py        DiscoveryResponder, NetworkScanner
│   ├── network.py          NetworkInfo, ArpTable, HostResolver
│   ├── identity.py         ServerIdentity
│   ├── autostart.py        AutostartManager (реестр Windows)
│   ├── firewall.py         FirewallManager (netsh)
│   ├── instance.py         InstanceGuard
│   ├── runner.py           ServerRunner (uvicorn)
│   ├── tray.py             TrayService
│   └── container.py        Services: сборка зависимостей
├── api/                    слой FastAPI
│   ├── app.py              ApiFactory
│   ├── security.py         TokenGuard
│   ├── schemas.py          модели запросов
│   └── routes/             system, devices, power, discovery, shortcuts
├── ui/                     веб-интерфейс (PWA и содержимое Android-приложения)
│   ├── index.html
│   └── static/ css · js · icons · manifest.webmanifest
├── android/                проект Android Studio (Java + WebView)
├── tools/make_icons.py     генерация иконок
└── tests/                  test_services.py, test_api.py
```
