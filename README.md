# WoL Shutdown

Небольшое приложение для Windows, которое выключает ПК, когда на него приходит магический пакет Wake-on-LAN.

Идея простая: одно приложение на телефоне и для включения, и для выключения ПК.

- Пока ПК **выключен**, магический пакет принимает сетевая карта, и компьютер включается.
- Пока ПК **работает**, тот же пакет принимает WoL Shutdown и выполняет `shutdown`.

## Возможности

- Минималистичный интерфейс на tkinter.
- Настройки: MAC-адрес, UDP-порты, задержка до выключения, период игнорирования после старта.
- Автозапуск вместе с Windows прямо из настроек (без ярлыков в `shell:startup`).
- Работа в системном трее: при автозапуске окно не показывается и не висит на панели задач.
- Кнопка «Отменить выключение», пока идёт обратный отсчёт.
- Журнал перехваченных пакетов в консоли.
- Все настройки сохраняются между запусками.

## Требования

- Windows 10 / 11
- Python 3.8 или новее
- Для значка в трее: библиотеки `pystray` и `pillow`

```
pip install pystray pillow
```

Без этих библиотек приложение работает, но сворачивается на панель задач, а не в трей.

## Запуск

```
python wol_shutdown.py
```

При первом запуске:

1. Впишите MAC-адрес этого ПК (`ipconfig /all`, строка «Физический адрес»). Он должен совпадать с тем, что указан в приложении на телефоне.
2. Нажмите «Сохранить».
3. Если Windows спросит про доступ к сети, разрешите его для частной сети.
4. По желанию включите «Запускать вместе с Windows» и снова нажмите «Сохранить».

## Настройки

| Параметр | Описание | По умолчанию |
|---|---|---|
| MAC-адрес | MAC этого ПК. Принимаются форматы `AA:BB:CC:DD:EE:FF`, `AA-BB-CC-DD-EE-FF`, `AABBCCDDEEFF` | пусто |
| UDP-порты | Порты, которые слушает приложение, через запятую | `9, 7` |
| Выключить через, сек | Задержка между пакетом и выключением. `0` выключает сразу | `10` |
| Игнорировать после старта, сек | Пакеты в этот период после запуска приложения игнорируются | `90` |
| Запускать вместе с Windows | Запись в реестре `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` | выкл |

Настройки хранятся в файле `%APPDATA%\WoLShutdown\config.json`.

Дополнительно приложение игнорирует повторные пакеты в течение 30 секунд после срабатывания (некоторые приложения шлют пакет несколько раз подряд).

### Зачем нужен период игнорирования после старта

Когда вы включаете ПК с телефона, некоторые приложения отправляют пакет несколько раз. Без защиты второй пакет мог бы прийти уже после запуска WoL Shutdown и сразу выключить только что включённый компьютер. Если ваше приложение шлёт пакеты редко, период можно уменьшить.

## Трей

- Крестик окна и кнопка «свернуть» прячут окно в трей.
- Двойной клик по значку или пункт «Открыть» возвращает окно.
- Пункт «Выход» полностью закрывает приложение (после этого ПК перестаёт реагировать на пакеты).
- При автозапуске приложение стартует только со значком в трее.

## Журнал в консоли

Каждый перехваченный пакет выводится в консоль с временем и результатом:

```
[21:04:12] Слушаю UDP-порты 9, 7, MAC AA:BB:CC:DD:EE:FF
[21:05:40] Магический пакет от 192.168.1.57, порт 9 — выключаю ПК через 10 с
[21:05:41] Магический пакет от 192.168.1.57, порт 9 — проигнорирован (повтор, пауза 30 с)
```

Также выводятся пакеты, адресованные другому MAC-адресу. Это помогает понять, почему ПК не реагирует: возможно, в приложении на телефоне указан не тот адрес.

- Запуск из cmd или PowerShell: `python wol_shutdown.py`
- Для собранного `.exe`: `wol_shutdown.exe --console` (открывает отдельное окно консоли, даже если сборка была с `--noconsole`)

## Сборка в .exe

```
pip install pyinstaller
pyinstaller --noconsole --onefile --hidden-import pystray._win32 wol_shutdown.py
```

Готовый файл появится в папке `dist`. Если после сборки переместите `.exe` в другую папку, заново включите автозапуск в настройках и нажмите «Сохранить», чтобы в реестре обновился путь.

## Как это работает

Магический пакет состоит из 6 байт `0xFF`, за которыми 16 раз повторяется MAC-адрес получателя. Приложение открывает UDP-сокеты на заданных портах, проверяет каждый входящий пакет на соответствие этому формату и вашему MAC-адресу и при совпадении выполняет:

```
shutdown /s /t <задержка>
```

Отмена выключения вручную: `shutdown /a`.

## Если что-то не работает

**ПК не включается пакетом**
- Включите Wake-on-LAN в BIOS/UEFI.
- В диспетчере устройств откройте свойства сетевой карты, вкладка «Управление электропитанием»: разрешите устройству выводить компьютер из ждущего режима и выберите «Только magic packet».
- В параметрах электропитания отключите «Быстрый запуск», если включение из состояния «выключено» не работает.

**ПК не выключается пакетом**
- Посмотрите журнал: приходит ли пакет и не указан ли в нём другой MAC.
- Телефон и ПК должны быть в одной подсети. Изоляция клиентов Wi-Fi и гостевые сети блокируют широковещательные пакеты.
- Проверьте, что брандмауэр разрешает входящие UDP-подключения для приложения на нужных портах.
- Если приложение на телефоне шлёт пакет на другой порт, добавьте его в список портов.
- Подождите, пока закончится период игнорирования после старта.

**Выключение не происходит после входа в систему**
- Автозапуск срабатывает только после входа пользователя в Windows. Если ПК стоит на экране ввода пароля, приложение ещё не запущено. Включите автоматический вход или запускайте приложение через Планировщик заданий.

**Несохранённые данные**
- Команда `shutdown /s` просит программы закрыться и может быть остановлена диалогом «Сохранить изменения?». Принудительное закрытие не используется, чтобы не терять данные.

## Ограничения

- Только Windows.
- Одновременно работает одна копия приложения.
- Приложение не проверяет, кто отправил пакет: любой, кто знает MAC-адрес и находится в вашей сети, сможет выключить ПК. Не используйте его в недоверенных сетях.
